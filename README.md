# Color of Sense — Art Gallery

React + Vite gallery app for classic and modern masterpieces, with category filtering and artist detail pages.

**Live demo:** https://YOUR-NETLIFY-URL

## Features
- Category filtering for artworks
- Nested routing (Home, Gallery, Artists, About, Contact)
- Responsive UI with React-Bootstrap
- Static JSON data + images from `/public/images`

## Tech stack
React 19 · Vite · React Router v7 · React-Bootstrap · Axios (optional)

## Getting started
```bash
git clone <repo-url>
cd my-art-gallery-react
npm install
npm run start
